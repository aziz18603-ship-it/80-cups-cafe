80 Cups Cafe — Website

Files:
- index.html: Arabic RTL landing page
- style.css: responsive styling and coffee-inspired visuals
- script.js: mobile navigation and current footer year

How to preview:
1. Keep all three files in the same folder.
2. Open index.html in a browser.

How to publish with GitHub Pages:
1. Create a new GitHub repository.
2. Upload index.html, style.css, and script.js to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the published URL shown on the Pages settings screen.

Notes:
- The menu only shows V60 and Espresso, which were in the information supplied. The rest of the menu and prices should be confirmed with the cafe before adding them.
- Business hours are not hard-coded as current hours; the page advises visitors to check Google Maps.
- The address, phone number, Instagram, rating and spending range are based on the supplied business information.
